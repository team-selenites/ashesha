# site/css

**What is here:** the site's styles.

| File | What it styles |
| --- | --- |
| `tokens.css` | The colours, type sizes and spacing for the three themes (Light, Dark and Colour-blind friendly) |
| `app.css` | Everything the pages share, and the sky viewer |
| `nav.css` | The menu |
| `home.css`, `spot.css`, `cryostella.css`, `beginnings.css` | One page each |
| `mark-candidate.css` | Mark a Candidate and My Candidates |

**Who owns it:** Pawana. `mark-candidate.css` is Shrashti's.

**How it connects to the rest:** every colour comes from `tokens.css`, so a theme changes the whole site. The reasons behind the look are in `docs/design-direction.md`.

**Status:** live.
