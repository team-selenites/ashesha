# docs

**What is here:** the decisions behind the site, written down so anyone can check them.

| File | What it covers |
| --- | --- |
| `design-direction.md` | How the site should look and feel, and why |
| `viewer-accessibility-spec.md` | What the sky viewer must do for blind, low-vision, colour-blind and deaf visitors |
| `sonification-design.md` | How sound is used, and how sound and speech are kept apart |
| `candidate-event-contract.md` | How the viewer and Mark a Candidate talk to each other |
| `cryostella-data.md`, `beginnings-data.md` | The data formats for Cryostella and Your Beginnings |
| `selene-voice-script.md` | Every recorded guide line, and how to record a new one |
| `selene-animation-recipe.md`, `character-prompts.md` | How the guides' pictures were made |
| `ai-use-log.md` | Every place AI helped, by date |
| `decisions/` | Single decisions with their reasons |
| `project/` | The plan and the roles, as they stood before the hackathon |

**Who owns it:** Pawana.

**How it connects to the rest:** the code comments point here for the reasons behind a choice.

**Status:** current to 15 November 2026. The files in `project/` are snapshots from before the hackathon and were not updated afterwards.
